Current focus

Research interests

My work combines precision measurements, model-agnostic searches, and hands-on detector development within the CMS experiment.

01

Tau precision physics

Leading analysis of tau anomalous magnetic moment and γγ → ττ cross-section measurements in ultraperipheral Pb–Pb collisions. The analysis is approved as CMS PAS HIN-24-011.

02

BSM resonance searches

Lead analyzer for a model-agnostic search for tri-resonant X → YY′ → bbWW decays, using combined CMS Run 2 and Run 3 data and a three-dimensional likelihood fit.

03

Phase-II detector R&D

Developing and testing the Tracker Endcap Pixel detector for High-Luminosity CMS, including an eight-module calibration framework and silicon-sensor characterization.
